# Changelog — FAZAH AI Arsenal (`github-ai-arsenal`)

All notable changes to this project are documented in this file.

## [6.5.0] — 2026-11-20
### Added
- **Official Interactive GitHub Pages Website** (`docs/index.html`) live at `https://fazah-arsenal.github.io/github-ai-arsenal/`.
- **1-Command Self-Updater (`fazah up` / `fazah update`)** to refresh scripts and the 20,078+ index directly from GitHub without `git`.
- **Automatic Global Version Synchronizer (`VERSION` & `scripts/bump_version.py`)** to keep every file, badge, and SVG in sync.
- **Global Launch Kit (`docs/LAUNCH_KIT.md`)** + **Community Health Suite** (`CONTRIBUTING.md`, `SECURITY.md`, `CHANGELOG.md`, Issue Templates).
- **Timeless Version-Free Hero Cover** (`assets/fazah-cover.jpg`) and refreshed `v6.5` SVG visual suite.

## [6.0.0] — 2026-11-20
### Added
- **1-Call Autonomous Tool Broker (`fazah g` / `arsenal_give_tool`)**: Picks #1 tool, runs supply-chain scan, extracts runnable code snippet, and optionally auto-pulls.
- **Token-Saving Code Snippet Extractor (`fazah sn` / `arsenal_get_snippet`)**.
- **Persistent Agent Experience Memory (`fazah mem` / `arsenal_memory`)**.
- **Isolated Python Sandbox (`fazah try`)**.
- **Full MCP Spec Support**: Upgraded `scripts/mcp_server.py` to **17 Native MCP Tools + 4 MCP Resources + 3 MCP Prompts**.

## [5.0.0] — 2026-11-20
### Added
- **Zero-Dependency Local Web UI (`fazah ui` / `scripts/web_ui.py`)**.
- **Deep Supply-Chain Security Scanner (`fazah scan`)**.
- **Smart Local Project Advisor (`fazah az .`)**.
- **Standard PyPI Packaging (`pyproject.toml`)** & Global MCP Registry manifests (`smithery.yaml`, `glama.json`, `Dockerfile`).

## [4.0.0] — 2026-11-20
### Added
- Ultra-short global **`fazah`** CLI command & subcommand aliases.
